# Веерное размещение: поведение редактора (для пользователя)

Форма **«Веерное размещение рекламы»** (`EditIssuesForm`) — расстановка выпусков
рекламной акции сразу по нескольким рекламным кампаниям в одном окне.

Документ описывает поведение, которое неочевидно из интерфейса. Технические
детали — в `docs/scenarios/range-issue-add-click-to-db.md`.

---

## 1. С чем работает веер

Веер работает **только с линейными кампаниями** акции. Модульные, спонсорские и
пакетно-модульные кампании в веере не участвуют вообще — они не показываются в
списке кампаний, их выпуски не попадают в сетку и в «Добавленные выпуски».

Если в акции **нет ни одной линейной кампании**, форма откроется с пустой сеткой и
погашенной панелью инструментов — веер тут не применим.

---

## 2. Выбор кампаний (блок «Кампании акции»)

Внизу слева — список линейных кампаний акции с галочками. Колонки:
**Радиостанция / Тип оплаты / Агентство**.

- Одна радиостанция может быть в списке **несколько раз** — если по ней в акции идёт
  несколько линейных кампаний, различающихся типом оплаты или агентством. Это
  нормально, строки независимы.
- **При открытии формы отмечены все** кампании.
- Изменив галочки, нажмите **кнопку обновления** (круговые стрелки) на панели
  инструментов — это та же кнопка, что и обычное обновление сетки. До нажатия
  «Обновить» сетка и все операции работают по прежнему набору.
- **Выбор не запоминается.** Закрыли форму — при следующем открытии снова отмечены все.

### Ноль галочек

Если снять все галочки и нажать «Обновить» — сетка станет пустой, панель
инструментов погаснет. Чтобы выйти из этого состояния: **поставьте любую одну
галочку** — она применится сразу, панель вернётся. Дальше отмечайте остальные и
жмите «Обновить».

### Смена выбора и уже расставленные выпуски

Выпуски, добавленные при одном наборе кампаний, при переключении на **другой**
набор:

- **остаются в базе** — никуда не деваются;
- **пропадают из сетки и из «Добавленных выпусков»** — их не видно;
- их **нельзя ни удалить, ни перенести** из нового выбора.

Чтобы снова с ними работать — верните галочки на те кампании и нажмите «Обновить».

---

## 3. Что значит «в контексте выбранных кампаний»

После «Обновить» под выбор кампаний попадает:

| Работает по выбранным кампаниям | Всегда по всей акции |
|---|---|
| Сетка (свободное время в ячейке = минимум по выбранным станциям) | Цена акции («Стоимость акции без скидок / со скидками») |
| Добавление выпусков (клик, массовое) | Панель статистики слева: «Выпусков», «Общее время» |
| Удаление выпусков | Пересчёт и корректировка платежа |
| Перенос выпусков (drag-and-drop) | |
| Подсветка «есть на всех станциях» | |
| Счётчик выпусков в шапке дня | |
| Шаблоны (Шаблон №3, генератор) — и расчёт цены, и раскладка | |

**Важно:** панель статистики слева (**Выпусков / Общее время / Стоимость**) всегда
показывает цифры по **всей акции**. Не пугайтесь, если слева выпусков больше, чем
видно в сетке при суженном выборе.

---

## 4. Цвета в ячейках сетки

### Цвет текста (остаток свободного времени / номера роликов)

Проверяются по порядку, срабатывает первый подходящий:

| Цвет | Значение |
|---|---|
| **Синий** | В этом получасе стоит выпуск текущей акции **во всех выбранных кампаниях** |
| **Красный** | Выпуск текущей акции есть, но **не во всех выбранных кампаниях** (частичный слот — см. §7) |
| **Бирюзовый** | В получасе есть выпуски **этой же фирмы в других акциях**, на всех выбранных станциях |
| **Оранжевый** | То же, но только на **части** выбранных станций |

- Бирюзовый и оранжевый — это **чужие акции той же фирмы**, предупреждение «фирма
  здесь уже висит», а не отметка вашей работы.
- С включённой кнопкой **«Учитывать неподтверждённые»** в бирюзовый/оранжевый идут
  ещё и неподтверждённые чужие выпуски.
- При **сужении** выбора кампаний оранжевый может стать бирюзовым, а красный —
  синим (стало «во всех выбранных»). Это не ошибка, а следствие того, что «все
  станции» теперь считается по меньшему набору.

### Фон ячейки (отдельный механизм, не связан с цветом текста)

| Фон | Значение |
|---|---|
| Розовый | Окно отключено (при «Показывать отключённые») |
| Голубой | Помеченное окно |
| Сиреневый | Прайм-тайм (при «Видеть прайм») |

### Жирный шрифт

При выбранной позиции ролика (первый / второй / последний) жирным выделены ячейки,
где эта позиция ещё **свободна**.

---

## 5. Добавление выпусков

### Клик по ячейке (режим редактирования)

Один клик добавляет выбранный ролик в этот получас **сразу во все выбранные
кампании**, одним и тем же роликом.

- Система ищет реальное рекламное окно в пределах этого получаса и берёт то, где
  **больше свободного времени**.
- Если хотя бы на одной выбранной станции подходящего окна нет — **не добавляется
  ничего ни на одной станции**, показывается ошибка. Частичного результата не бывает.
- **Повторный клик** по той же ячейке добавляет ещё один выпуск (дубль) — это
  специально, для нескольких выходов в одном получасе.
- Через веер в один получас ставится **один и тот же ролик** на все выбранные
  кампании. Разные ролики на разных станциях в одном получасе появляются только
  если их правили **не через веер** (тогда получас становится красным).

### Массовое добавление в выбранные окна

Выделите мышью несколько ячеек (протяжка ЛКМ или Ctrl) и вызовите добавление.
В отличие от одиночного клика: если по части окон не получилось — **остальные всё
равно добавятся**, а по неудачным покажется список ошибок.

---

## 6. Удаление выпусков

### Массовое удаление (выделение окон + Delete)

- Удаляются выпуски выделенных окон **по выбранным кампаниям**.
- **Красные окна тоже удаляются** — по тем кампаниям, где выпуск фактически есть.
- Часть может не удалиться: подтверждённый выпуск **в прошлом** или за периодом,
  **закрытым трафик-менеджером**, удаляет только администратор или трафик-менеджер.
  По таким выпускам покажется список ошибок, остальные удалятся.

### Из списка «Добавленные выпуски»

Удаление строки списка удаляет соответствующий выпуск (на всех выбранных
кампаниях этого слота).

---

## 7. Частичные («красные») слоты

**Красный слот** — выпуск текущей акции есть, но не во всех выбранных кампаниях.
Когда появляется:

- кампании акции идут разными датами, и получас попал в интервал одних, но не других;
- выпуски правили в обход веера — напрямую через обычную форму кампании.

Красный слот **не попадает в список «Добавленные выпуски»** (там только то, что
общее для всех выбранных кампаний).

### Перенос и удаление красных слотов

Работают. Ключевое правило: операция идёт **ровно по тем кампаниям, где выпуск
реально стоит**.

- Перенос красного слота «2 из 5» → в целевом окне тоже «2 из 5» (останется
  красным). Остальные три кампании не затрагиваются.
- Если в красном слоте на разных станциях стоят **разные ролики или позиции** —
  каждая пара «ролик + позиция» переносится своей группой.

---

## 8. Перенос выпусков (drag-and-drop)

Перетащить можно:

- **синюю или красную ячейку** сетки — **только в режиме просмотра** (в режиме
  редактирования клик по ячейке добавляет выпуск);
- **строку из списка «Добавленные выпуски»** — в любом режиме.

Поведение:

- **Синий слот**: переезжают все выпуски получаса, по выбранным кампаниям.
- **Красный слот**: переезжает в том же составе кампаний (см. §7). Красные слоты в
  списке «Добавленные выпуски» не показываются — их можно тащить только из ячейки
  сетки.
- **Ролик и позиция** сохраняются от исходного выпуска.
- **Если в целевом окне не хватает места хотя бы одной из кампаний** — перенос
  **не выполняется целиком**: показывается ошибка, ничего не переносится и не
  удаляется. Это сделано намеренно: лучше явный отказ, чем частичный перенос с
  расхождением между станциями.

---

## 9. Список «Добавленные выпуски»

- Показывает то, что **общее для всех выбранных кампаний** (пересечение). Если в
  получасе у одной кампании 2 выпуска, а у другой 1 — в списке будет **1**.
- Одна строка — один получас, без привязки к станции (ролик один и тот же на всех).
- Красные (частичные) слоты сюда **не попадают**.
- Список строится при открытии формы и при каждом нажатии «Обновить».

---

## 10. Цена акции и платёж

- После **каждого** добавления или удаления цена акции пересчитывается.
- Если цена акции **уменьшилась** и акция **подтверждена** — платёж по акции
  корректируется автоматически.
- Цена акции считается по **всей акции**, независимо от выбора кампаний в вееере.

---

## 11. Прочее

- **«Отменить»** (кнопка отмены шаблона) — убирает последнюю пачку выпусков,
  добавленную по шаблону.
- **Счётчик выпусков в шапке дня** считает выпуски по выбранным кампаниям: один
  клик добавления увеличивает его на число выбранных кампаний.
