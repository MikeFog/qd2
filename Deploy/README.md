## Перед запуском

1. Резервная копия базы:
   `BACKUP DATABASE <база> TO DISK = N'...' WITH COPY_ONLY, INIT;`
2. Запускать **от sysadmin** (скрипты читают определения процедур; без прав остановятся с сообщением).
3. Каждый скрипт — **один батч в транзакции** и **применяется сразу** (в конце `COMMIT`; пробного режима нет).
   Защитные проверки в начале при несоответствии базы останавливают скрипт сообщением «Остановлено: …» (ничего не применено).
   Не разбивать на батчи через `GO`.

## Как запускать каждый скрипт

**SSMS.** Открыть файл, выбрать нужную базу, выполнить (F5). Скрипт применяется сразу. В конце выводится
сообщение «`=== ГОТОВО: изменения применены и зафиксированы (COMMIT) …`»; если выше есть «**Остановлено: …**» или
«… уже … — ничего не делаем» — ничего не менялось, причина в тексте.

**sqlcmd** (кодировка важна, файлы в UTF-8 с BOM):

```
sqlcmd -S <сервер>\<инстанс> -d <база> -E -f 65001 -b -y 40 -i 01_brand-cleanup-1-stat-RollerStatistic.sql
```
