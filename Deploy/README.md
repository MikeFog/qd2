
**«Incorrect syntax near '﻿'» в первом пакете (SSMS 22) — безвредно.** Файлы — UTF-8 **с BOM**, и SSMS отдаёт
BOM серверу как символ в начале первого пакета (до первого `GO`); пакет падает, остальные выполняются. BOM не
убираем: без него `sqlcmd` без `-f 65001` (и SSMS, если не угадает кодировку) молча портит кириллицу в строках
`N'...'` (проверено 07.10.2026: `Ж` → `Р`). **Правило для новых скриптов:** первый пакет — только шапка-комментарий
и `SET NOCOUNT ON;`, затем `GO`; ничего значимого до первого `GO` не ставить.
